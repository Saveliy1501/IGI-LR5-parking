💻 Пример листинга


function calculateParkingPrice(hours) {
    const ratePerHour = 5;
    let total = hours * ratePerHour;
    if (hours > 24) {
        total = total * 0.9; // скидка 10%
    }
    return total;
}

Демонстрация глобальных атрибутов

1. id — уникальный идентификатор элемента

2. class — класс для CSS/JS

3. style — inline-стили

4. title — наведите курсор

5. lang — гэта тэкст на беларускай мове

6. dir — текст справа налево (עברית)

7. hidden — этот текст скрыт

(элемент с hidden не отображается)

8. tabindex — этот элемент доступен по Tab

9. accesskey — нажмите Alt+A для фокуса

10. contenteditable — этот текст можно редактировать (кликните)

11. spellcheck — проверка орфографии (начните печатать с ошибкой)

12. translate — этот текст не переводится (AutoCar)

13. data-* — пользовательские данные (data-company, data-year)

14. draggable — этот текст можно перетащить
